# v5：依赖、文件目录与只读源码检索误拦修复

基线：main 91ea4d1；事故是 xss 依赖被内置正则直接判漏洞利用、长 rg 引用超过120字符而触发故障、编号 Magisk 路径列表被复核误当安装提权。真实原始请求未提供；路径已替换为 /workspace/demo，只使用日志里的结构与判定流程构造回归。

## 修改原则

1. 禁用真正的操作，不把提到某能力自动视为正在实施。XSS 固定基线由孤立名词改为紧邻攻击/测试动作描述；不影响管理员自定义禁用规则的终态否决。
2. 只匹配到真实原文不够：纯目录/依赖与普通搜索形态的模型阻断，在锁定前有一次操作证据校核。整个请求和原任务锚点不删除；不是目录或命令白名单。凭据读取、组合命令和混合操作仍检查并拒绝。
3. 证据建议短，但允许有界长引用逐字验证。整段必须匹配，不能截出一个存在的前缀替虚构尾部过关。超1024字符/4096字节、缺证据、不匹配都拒绝。
4. 重提操作证据不允许无限重试。仍无具体操作依据或调用/解析失败，返回555审计故障；有效的具体拒绝仍终态拒绝，后续allow无权推翻。
5. 未支持输入保留拒绝并提供形状诊断；同时区分审计覆盖与拒绝已完成。未知类型名称可能携带私密数据，日志只暴露unknown及生成的字段位置。
